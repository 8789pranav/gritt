## 📊 Difficulty Progression

### By Grade Level

**Kindergarten**:
- Logic: Simple patterns, basic categorization
- Spelling: CVC words, basic sight words
- Speaking: 5-7 word sentences, simple structure
- Comprehension: Short stories with sound effects

**First Grade**:
- Logic: Analogies, sequences, simple matrices
- Spelling: Digraphs, blends, common sight words
- Speaking: 7-9 word sentences, past tense
- Comprehension: Longer narratives, emotional themes

**Second Grade**:
- Logic: Multi-step problems, complex patterns
- Spelling: Complex blends, inflected endings
- Speaking: 7-9 words, academic vocabulary
- Comprehension: Realistic fiction, inference questions

**Third Grade**:
- Logic: Abstract reasoning, meta-cognition
- Spelling: Multi-syllable words, advanced patterns
- Speaking: 8-10 words, complex syntax
- Comprehension: Mystery/adventure, deeper themes

## 🔄 How Tests Are Administered

### Logic Assessment
1. Student receives 10 questions for their grade
2. Selects answer from 4 options
3. Response time tracked
4. Attempts counted
5. Cognitive tags awarded based on performance

### Spelling Assessment
1. Student hears word in sentence (audio)
2. Types the word
3. System scores phonics features
4. Points awarded for correct features
5. Regular words: 1-5 points, Sight words: 1 point

### Speaking Assessment
1. Student sees sentence
2. Reads aloud (audio recorded)
3. AI analyzes pronunciation and fluency
4. Scores accuracy, fluency, prosody
5. Provides detailed feedback

### Comprehension Assessment
1. Student listens to story (audio narration)
2. Answers 4 multiple-choice questions
3. Questions test literal and inferential comprehension
4. Immediate feedback provided
